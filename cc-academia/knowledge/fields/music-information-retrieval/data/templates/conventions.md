# Conventions: data

- **Metrics and baselines**: precision, recall, F1 at frame and note level; tablature-specific metrics (TDR);
  the baseline is a public reference model; mean +/- std over seeds only in the newest papers; significance tests rare.
- **Ablations**: one design choice removed or swapped at a time, reported in the main table and ranked in prose.
- **Dataset description**: hours, number of tracks and players, recording hardware, annotation procedure, split, licence.
- **Reproducibility**: code and data links in footnotes; ISMIR adds an ethics statement (related: data.reproducible).
