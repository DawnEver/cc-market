# Venue source: ieee

IEEE author guide and editorial style (SOURCES.md: S1, S5): format rules (`must` only), dimension values and
format vocabulary. Files: `prose/rules.tsv`, `prose/values.tsv`, `prose/vocabulary/word-choice.tsv`,
`data/rules.tsv`, `equation/rules.tsv`, `reference/rules.tsv`, `reference/vocabulary/forms.tsv`,
`figure/rules.tsv`, `caption/rules.tsv`.

Venue note (information, not a binding rule): the IEEE author guide (S1 VI-I-1, "Figure axis labels") writes axis units in
parentheses, "Magnetization (A/m)". The bracket style is the author's dimension `figure.axis-unit-brackets`; no venue
value sets it.
