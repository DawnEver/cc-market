# Preset: mingyang-bao

A named set of style choices: dimension values, each with evidence (a dated user ruling, described neutrally), and
recommended phrases (never flagged). A preset holds nothing else; a project selects it with `preset mingyang-bao` in
`.academia/profile.tsv`. Built from the user's rulings (2026-11-08 to 2026-11-23) and approved, unpublished text by the
style-profiling workflow.

Unpublished text is never quoted here. Every example drawn from it is a paraphrase in another technical setting with
invented numbers, marked `paraphrase; original withheld until publication` (`evidence` of values.tsv, `why` of the
vocabulary), so the originals can be restored after publication.

| File | Holds |
|---|---|
| `prose/values.tsv` | self-reference (either), relative clause (nonrestrictive-only), connectives avoided (however, whereas), hedging, sentence length (35 and 7 words), short-sentence run, openers, numbers in abstract and conclusion (finding-then-value), abstract result sentences, conclusion tense, results heading style (topic) |
| `prose/vocabulary/terms.tsv` | recommended phrases with placeholders and the contrast link "In contrast" |
| `figure/values.tsv` | 8 pt Computer Modern, no scaling, Okabe-Ito, linear axes, 4 % headroom, panel letters bottom-left upright, panel labels top-right, legend in the first panel, side-by-side width 0.48, square brackets for axis units, characteristic marks on the top axis |
| `table/values.tsv` | square brackets for units in tables |

Corpus slips are not style: they are common correctness rules and never values or phrases here.
